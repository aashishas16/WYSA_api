# 💤 Wysa Sleep App - Backend Developer Mini Project

This repository contains the backend design and prototype implementation for **Challenge 1** of the Wysa Backend Developer Internship Assessment. The project focuses on designing REST APIs and data models to support the onboarding and sleep assessment flow of the [Wysa for Sleep](https://play.google.com/store/apps/details?id=sleep.app.relax.calm&hl=en_IN&gl=US) app.

## 📌 Overview

The Wysa Sleep app takes users through a short sleep assessment during onboarding. This project outlines:
- ✅ REST API design for sleep onboarding
- 🗃️ Database schema (SQL & NoSQL)
- 🧪 Prototype server implementation (bonus)
- 📊 Suggestions for analytics-friendly storage (bonus)

## 🚀 Features

- RESTful API for onboarding flow
- User signup with unique nickname and password
- Endpoint security using basic auth/token (for protected routes)
- Minimal frontend (if implemented)
- Sample data and API request/response formats
- Optional: Analytics-ready data design

## 🧱 Tech Stack

- **Backend**: Node.js / Express.js or Python / Flask
- **Database**: MongoDB / PostgreSQL
- **Authentication**: JWT or Basic Auth
- **Tools**: Postman (for API testing), Swagger (optional for API docs)
